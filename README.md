## AI vs. Human-Generated Image Detection

### Project Overview
Web application aims to develop and evaluate a deep learning model, specifically AlexNet, to distinguish between authentic human-generated images and those generated by state-of-the-art AI models. 
The increasing sophistication of generative AI necessitates robust tools for content authentication.

### Deployment
The trained model is deployed through two interactive interfaces:
- **Streamlit:** A feature-rich web application (`app.py`) has been deployed to **Streamlit Cloud**,
  offering a dynamic result display for image classification, confidence visualization, and error handling.\
  You can access the live application [**Streamlit-Cloud**](https://detect-ai-vs-human-generated-images-iduedmthstucw83xzlmt5t.streamlit.app/).
- **Gradio:** A simple and quick web interface (`gr.Interface`) is set up to allow users to upload an image and get an immediate classification (AI-generated or Human-generated) along with a confidence score.

### Evaluation
After training, the model's performance is evaluated on a validation set acheiving **Acuuracy = 93%**, and comprehensive metrics including classification report.

### Dataset
The core of this project relies on a specialized dataset comprising [**kaggle**](https://www.kaggle.com/datasets/alessandrasala79/ai-vs-human-generated-dataset):
- **Authentic Images:** Sampled from Shutterstock across various categories, including a balanced selection featuring human subjects.
- **AI-Generated Equivalents:** Images generated using advanced generative models, paired with their authentic counterparts.

This structured pairing facilitates direct comparison and robust training for image authenticity detection. The dataset is split into:
- `train.csv`: 79,950 images for model training.
- `test.csv`: 19,986 images for final evaluation (though only used for pre-processing in this notebook).
